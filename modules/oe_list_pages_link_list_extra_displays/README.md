# OE List Pages Link List Extra Displays

This module builds on `OE List Pages Link List Displays`. On top of the main
display, it lets editors configure extra link list displays on a list page.
Visitors can then switch between them using tabs.

## How to use

When you edit a list page, the `Extra displays` section lets you add any
number of extra displays, each with its own display plugin and configuration.
You can reorder them by drag and drop. The main display is always shown first.

Each display needs a tab title. You can pick one of the predefined (and
translatable) titles, `List`, `Grid` or `Map`, or choose `Custom` and type your
own title. If there are extra displays, the main display also needs a tab title.
